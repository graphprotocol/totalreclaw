# NanoClaw -- Not Supported

NanoClaw is not supported. TotalReclaw no longer provides a setup guide for it, and we do not recommend installing `@totalreclaw/skill-nanoclaw`.

Use a supported client instead: [OpenClaw](openclaw-setup.md), [Hermes](hermes-setup.md), [Claude Desktop](claude-desktop-setup.md), [Claude Code / Cursor / Windsurf](claude-code-setup.md), or [Codex](codex-setup.md).

Never put your recovery phrase in a file or an environment variable by hand. Set up your account through the pairing flow in a supported client.
